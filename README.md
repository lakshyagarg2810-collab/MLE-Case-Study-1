# Hospital Readmission Prediction

## Overview

This project predicts whether a patient will be readmitted to the hospital within 30 days using the Diabetes 130-US Hospitals dataset.

## Dataset

Diabetes 130-US Hospitals for Years 1999–2008.

The original dataset is not included in this repository.

## Objective

To develop a machine learning classification model for predicting 30-day hospital readmission.

## Model

Logistic Regression with L2 Regularization

## Evaluation Metrics

- ROC-AUC
- Precision
- Recall
- F1 Score
- ROC Curve

## Project Files

- `Hospital_Readmission_Prediction.ipynb` — Complete analysis and model
- `predictions/` — Final model predictions
- `results/` — ROC curve and other results
